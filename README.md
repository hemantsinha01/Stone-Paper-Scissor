# Stone Paper Scissor

A simple browser-based Stone Paper Scissor game built with HTML, CSS, and JavaScript.

## Project structure

- `stone paper scissor/index.html` – main page markup
- `stone paper scissor/style.css` – styling for the game UI
- `stone paper scissor/index.js` – game logic and score handling

## How to run

1. Clone or download this repository.
2. Open `stone paper scissor/index.html` in any modern web browser.
3. Click on Rock, Paper, or Scissors to play against the computer.

## Game rules

- Rock beats Scissors.
- Scissors beat Paper.
- Paper beats Rock.
- If both players choose the same option, the round ends in a tie.

## Features

- Interactive game interface
- Score tracking for the player and computer
- Rules pop-up inside the game
